# AITools

Данный проект был разработан в качестве курсового проекта.

Проект представляет собой агрегатор запросов с естественного языка. Пользователь вводит запрос на своём естественном языке, система обрабатывает его, определяет, в каком виде он хочет получить ответ (текст, картинка и т.д.) и с помощью нейронных сетей генерирует ответ на запрос пользователя.

Проект находится на начальной стадии разработки. Разработка ещё не завершена.
